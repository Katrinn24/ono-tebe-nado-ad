# Оно тебе надо

Учебный проект Яндекс Практикума — одностраничный сайт аукциона необычных вещей, в которые когда-то никто не верил.

Проект выполнен по макету Figma с использованием HTML и CSS. Основная задача — создать аккуратную страницу с несколькими смысловыми блоками и передать композицию оригинального макета.

## О проекте

Страница включает:
- шапку с навигацией и контактной информацией;
- обложку с названием проекта и кнопкой;
- раздел с тремя карточками аукционных лотов;
- информационный раздел «Об аукционе»;
- подвал с контактами, навигацией и социальными сетями.

Целевая ширина страницы — 1100 px. Проект ориентирован на экран ноутбука.

## Что реализовано

1. Подготовлена семантическая HTML-структура с элементами `header`, `main`, `section` и `footer`.
2. Созданы блоки обложки, карточек лотов, информации об аукционе и подвала.
3. Добавлены тексты, изображения, логотипы и иконки социальных сетей.
4. Подключены локальные шрифты Raleway Regular и Raleway Bold.
5. Настроены стили и оформление страницы с помощью CSS.
6. Для расположения элементов используются Grid и Flexbox.
7. Добавлены фоновые изображения, затемнение карточек и обложки, а также ссылки для навигации по странице.

## Технологии

| Технология | Использование |
| --- | --- |
| HTML5 | Семантическая разметка страницы |
| CSS3 | Стилизация и расположение элементов |
| Flexbox | Выравнивание и размещение элементов |
| CSS Grid | Построение сеток шапки, разделов и подвала |
| БЭМ | Организация CSS-классов |
| Raleway | Локально подключённые шрифты |
| SVG и JPG | Логотипы, иконки и изображения |
| Git и GitHub | Контроль версий и хранение проекта |

## Организация файлов

- `index.html` — HTML-разметка и содержимое страницы.
- `styles/global.css` — общие настройки и сброс стандартных отступов.
- `styles/style.css` — стили отдельных блоков страницы.
- `fonts/fonts.css` — подключение локальных шрифтов.
- `images/` — изображения, логотипы и иконки социальных сетей.
